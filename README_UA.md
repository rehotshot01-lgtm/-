# PRAВДА для Android — основа v0.1

Цільовий пристрій: Infinix NOTE 30, MediaTek Helio G99, 8 ГБ фізичної RAM, Android 14.

## Що вже є у вихідному коді
- Android-застосунок на Kotlin + Jetpack Compose.
- Локальна база Room для задач і журналу аудиту.
- Інтерфейс українською з розділами та історією задач.
- Двигун задач і контроль перевірки кандидатів.
- Маніфест без дозволу `INTERNET`: застосунок не має мережевого доступу.

## Чесний статус
Це **вихідний код MVP, а не готовий APK і не завершений автономний ШІ**. `DemoModelAdapter` наразі повертає демонстраційний текст і не запускає мовну модель. Реальний локальний inference backend ще треба під'єднати та перевірити на самому Infinix. Не встановлюй випадкові файли моделей з невідомих джерел.

Також ще не реалізовано безпечне виконання довільного коду: не запускай неперевірені програми. До додавання справжньої ізоляції агент має лише планувати та зберігати задачі.

## Як зібрати застосунок
1. На комп'ютері встанови Android Studio та JDK 17.
2. Розпакуй архів і відкрий у Android Studio папку `OfflineAI_Pravda`.
3. Дозволь Gradle синхронізувати залежності.
4. Під'єднай Android-телефон через USB з увімкненим USB debugging або використай емулятор.
5. Запусти конфігурацію `app`.

Потрібен комп'ютер із Android Studio для збирання APK. Сам цей архів не є APK, який можна встановити натисканням.

## План до автономної версії
1. Підібрати компактну модель та сумісний Android runtime для Helio G99 / 8 ГБ RAM.
2. Замінити `DemoModelAdapter` на реальний локальний inference backend; перевірити запуск без мережі.
3. Додати імпорт моделі з файлового сховища та перевірку вільного місця.
4. Реалізувати обмежений файловий інструментарій із явним підтвердженням запису/видалення.
5. Лише після цього додавати виконання коду в ізольованому середовищі, тести, резервні копії та відкат.

## Стек
Kotlin, Jetpack Compose, Room, Coroutines, Android SDK. Використовуються безкоштовні інструменти; жоден платний API не потрібен.
