# Як отримати APK ПРАВДА без платних інструментів

Цей архів підготовлено для автоматичного збирання APK у GitHub Actions. Сам APK не додається, бо для його компіляції потрібні Android SDK і Gradle, яких немає в середовищі створення цього архіву.

## Кроки з Android
1. Увійди або створи обліковий запис на https://github.com/.
2. Створи приватний репозиторій (наприклад, `pravda-android`).
3. Завантаж сюди вміст папки `OfflineAI_Pravda` разом із прихованою папкою `.github`. Найпростіше зробити це з комп'ютера; на Android можна скористатися браузером у режимі «Версія для ПК» або застосунком Git-клієнта.
4. Відкрий вкладку **Actions** у репозиторії та дозволь запуск workflow, якщо GitHub запитає.
5. Вибери **Build PRAVDA APK** → **Run workflow**.
6. Після завершення відкрий запуск workflow унизу сторінки, у розділі **Artifacts** завантаж `PRAVDA-debug-APK` і розпакуй ZIP.
7. Відкрий `app-debug.apk` на телефоні й дозволь встановлення з цього джерела, якщо Android запитає.

## Важливо
- Це debug APK для тестування, не підписаний реліз для Google Play.
- Збірка ще не означає, що застосунок містить справжню локальну мовну модель: адаптер ШІ у версії 0.1 є демонстраційним.
- Не завантажуй APK у публічний репозиторій, якщо не хочеш оприлюднювати вихідний код.
- Якщо збірка впаде, відкрий журнал цього запуску й збережи помилку для виправлення.
